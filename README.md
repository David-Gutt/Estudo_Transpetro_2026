## 📖 Sobre o que é este projeto?

Este repositório contém um **sistema completo de preparação para o concurso Transpetro 2026 - Ênfase 1 (Administração e Controle)**, organizado para levar você da base até a aprovação em **50 dias (até 29/11/2026)**, deixando 1 semana final para revisão leve antes da prova em 06/12/2026.

O sistema foi inspirado no **estilo Cesgranrio**, que cobra:
- Textos longos com alternativas quase idênticas
- Troca de 1 palavra para mudar o sentido
- Literalidade do edital (p.46 - Português, p.48-55 Específicos)
- Pegadinhas clássicas (haver impessoal, fazer tempo, crase obrigatória)

Tudo funciona **100% offline** com 2 cliques (`file://`), sem precisar instalar nada, e também online via GitHub Pages.

## 🎯 Como funciona o sistema?

### 1. **Ciclo de Teoria e Prática - Regra 60/40**

Cada dia tem exatamente:

**40% Teoria (média 1h):**
- 3 bullets de resumo
- Mapa mental (causa → consequência)
- Referência edital p.46 + apostila p.XX
- Foco Cesgranrio: o que a banca mais cobra

**60% Prática (média 1h30):**
- 12 questões estilo Cesgranrio comentadas
- Quando erra, já aparece explicação completa + dica de como a banca cobra
- Cronômetro travado 2h (não deixa pausar pra colar)

> **Por que 60/40?** Neurociência mostra que 60% de prática ativa retém 75% mais que só ler teoria.

### 2. **Revisões Periódicas - Combate à Curva do Esquecimento (Ebbinghaus)**

Sistema automático:

```
D+1  → Revisão 10min (mesmo dia seguinte)
D+3  → Revisão 15min (3 dias depois)
D+7  → Revisão 20min (1 semana)
D+15 → Revisão 30min (15 dias)
```

No topo do plano sempre aparece:
```
🔔 Hoje: Revisar Dia 1 (D+1) e Dia 2 (D+3)
```

Se não revisar, o card vira **REVISAR** em vermelho. Cada erro vai pro **Caderno de Erros** que é revisado nessas datas.

### 3. **Estudo Intercalado (Interleaving)**

Todo dia tem **obrigatoriamente**:
- 1 tópico de **Português** (8 tópicos edital)
- 1 tópico de **Matemática** (10 tópicos edital)
- 1 tópico de **Específico** (Ênfase 1)

**Nunca repete a mesma matéria 2 dias seguidos.** Isso força seu cérebro a diferenciar e não saturar.

Exemplo Dia 3:
- PORT: Classes (onde/cujo/haver)
- MAT: Funções 1º/2º grau + Eq. Exponencial `4^x-5*2^x-6=0`
- ESP: ESG e Sustentabilidade

### 4. **Ciclo de Matérias**

```
FASE 1 - BÁSICOS (Dia 1-10) - 2h30/dia
├── Português: Por que/Porque, Ortografia (hífen anti-inflamatório), Classes, Crase, Concordância, Pontuação, Interpretação, Coesão
```

### 5. **Simulados em Condições Reais**

Cada quiz tem:

- **Cronômetro 2H AO VIVO** - 02:00:00 travado, se zerar encerra
- **Pausar / Reiniciar** - mas conta tempo total
- **MAPA DA PROVA 1-12** - clica no número e vai pra questão, mostra feitas (cinza), atual (amarelo #d4ff00)
- **Progresso 0/12 + Barra** - visual
- **Acertos / Feitas / Faltam** - 3 cards
- **Bloqueia colar** - foco total
- **Explicação após responder** - não mostra antes
- **Relatório Final**:
  - Acertos gerais X/12 + % + Meta Cesgranrio 75%
  - Tempo médio por questão + Total usado
  - Ranking Simulado (Top 18% / 42% / 71% - simulação com 1.247 candidatos Ênfase 1)
  - Desempenho por matéria (PORT/MAT/ESP) com barra
  - Tempo por questão Q1: 45s ✓ / Q2: 120s ✗
  - Botão Refazer / Voltar ao Plano (marca como FEITO)

## 🧠 Por que este método funciona?

1. **60/40**: Você aprende fazendo, não só lendo. Cada erro vira aprendizado com explicação imediata.
2. **Revisão Espaçada D+1 D+3 D+7 D+15**: Combate a Curva do Esquecimento de Ebbinghaus. Você revisa antes de esquecer.
3. **Estudo Intercalado**: Misturar PORT+MAT+ESP no mesmo dia cria conexões neurais mais fortes que estudar 1 matéria por dia.
4. **Ciclo de Matérias**: Fase 1 base → Fase 2 específico → Fase 3 avançado → Fase 4 revisão turbo. Cada fase usa a anterior.
5. **Simulados Reais**: Cronômetro, pressão, ranking. Seu cérebro se acostuma com a prova antes da prova.
